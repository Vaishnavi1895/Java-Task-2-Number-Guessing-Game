# 🎮 Number Guessing Game | OIBSIP Task 2

## 📌 Project Overview

The **Number Guessing Game** is a Java Swing-based desktop application developed as part of the Oasis Infobyte (OIBSIP) Java Development Internship.

The game generates a random number, and the player attempts to guess it within a limited number of attempts. It provides hints to help the player determine whether the guessed number is higher or lower than the target number.

## ✨ Features

- 🎨 Interactive graphical user interface.
- 🎚️ Three difficulty levels: Easy, Medium, and Hard.
- 🎲 Random number generation.
- ⬆️ Higher and lower hints.
- 🔢 Attempt counter.
- 🏆 Score tracking.
- 🎉 Win and lose messages.
- 🔄 Play Again option.
- ✅ Input validation to handle invalid entries.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **IDE:** Eclipse IDE
- **Concepts:** Random number generation, loops, conditional statements, and event handling.

## ⚙️ How to Run

1. Install the Java Development Kit (JDK).
2. Open Eclipse IDE.
3. Create or import the Number Guessing Game project.
4. Place `NumberGuessingGame.java` inside the source folder.
5. Ensure the file contains the correct main method.
6. Right-click the main class.
7. Select **Run As → Java Application**.
8. Choose a difficulty level and start guessing the number.

## 🎮 How to Play

1. Launch the game.
2. Select Easy, Medium, or Hard difficulty.
3. Enter your guess in the input field.
4. Read the hint displayed by the application.
5. Continue guessing within the allowed attempts.
6. Win by guessing the correct number before attempts run out.
7. Select **Play Again** to start a new round.
